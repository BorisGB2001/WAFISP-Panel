0.6.4: ширина колонок и коды стран

- Во всех таблицах ширину колонки можно менять, потянув за правый край заголовка. Ширина запоминается в браузере для каждой таблицы; двойной щелчок по краю возвращает автоматическую ширину. Если колонки не помещаются, таблица прокручивается вбок, кнопки в последней колонке не пропадают.
- После каждого адреса в таблицах (журнал атак, карточка события и адреса, блокировки, белый список, автобан, массовый бан, общие блокировки, ловушки, аудит, топ атакующих) стоит код страны: `US`, `RU`, `DE` и т. д., `LAN` для частных сетей, «—», если база страну не знает. При наведении видно название страны.
- Коды берутся из базы GeoIP (`geoip_db`, формат MaxMind). Без базы у публичных адресов кода нет.
