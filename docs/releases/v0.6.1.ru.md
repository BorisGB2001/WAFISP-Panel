0.6.1: общий бан-лист без токена GitHub

- Общий бан-лист работает через git по SSH с ключом развёртывания каждого сервера: ключ создаётся на сервере, даёт запись только в один репозиторий, токен аккаунта на серверах не нужен. git на сервере ставить не нужно — он встроен в панель.
- Ключ сервера GitHub зашит в панель: подменить GitHub по дороге нельзя.
- Вариант с токеном (token_file) остаётся.
